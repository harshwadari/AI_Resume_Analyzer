# Project context and implementation workflow

Read `PROJECT_CONTEXT.md` before planning or implementing recruiter features. It records the user's agreed product direction, architecture, and phase roadmap.

Implement only the phase or task the user currently requests. After completing that scope and appropriate checks, report the result and wait for the user to verify it and explicitly request the next phase. Do not automatically implement the rest of the roadmap.

Preserve the existing React + Node/Express + MongoDB application. The planned Python/FastAPI AI service extends the application; it does not replace it.
